# Talento Smart 1.1.0

The integration is now self-contained for HACS installation.

## Install

1. Install Talento Smart in HACS.
2. Restart Home Assistant.
3. Add the Talento Smart integration.

The custom Lovelace card is bundled with the integration and is loaded automatically by Home Assistant. No `/config/www/` copy and no manual dashboard resource are required.

The BLE protocol is unchanged from the working 1.0.x baseline.
